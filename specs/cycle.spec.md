# Cycle 출력물 명세

## 구조적 명세 (결정론적 검증)
- [ ] `# 요구사항 구체화 - Cycle {n}` 제목 존재
- [ ] `## 이번 사이클 질문` 섹션 존재
- [ ] `## 사용자 응답` 섹션 존재
- [ ] `## 현재까지 구체화된 요구사항` 섹션 존재
- [ ] `## 고려했지만 미반영된 사항` 섹션 존재
- [ ] `## 다음 사이클 검토 필요 사항` 섹션 존재
- [ ] `## 참고 자료` 섹션 존재

## 정량적 명세 (결정론적 검증)
- [ ] 전체 길이 200자 이상
- [ ] Cycle 0: 질문 없어도 됨 (초기 요구사항 수집)
- [ ] Cycle 1+: 질문이 있거나, "추가 질문 없음" 명시

## 의미적 명세 (Subagent 검증)
- [ ] 이전 사이클 대비 새로운 정보 포함
- [ ] 사용자 응답 내용이 요구사항에 반영됨
- [ ] 본문의 주장/판단에 인용 표시 존재 (예: [1], [2])
- [ ] 인용 표시가 `## 참고 자료`의 항목과 매칭됨
- [ ] `## 참고 자료`에 출처 URL과 원문 내용이 함께 기록됨
