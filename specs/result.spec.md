# 최종 결과물 명세

## 구조적 명세 (결정론적 검증)
- [ ] `# 최종 요구사항` 제목 존재
- [ ] `## 개요` 섹션 존재
- [ ] `## 상세 요구사항` 섹션 존재
- [ ] `## 고려했지만 미반영된 사항` 섹션 존재
- [ ] `## 구체화 히스토리` 섹션 존재
- [ ] `## 참고 자료` 섹션 존재

## 정량적 명세 (결정론적 검증)
- [ ] 전체 길이 500자 이상

## 의미적 명세 (Subagent 검증)
- [ ] 개요와 상세 요구사항의 일관성
- [ ] 실행 가능한 수준의 구체성
- [ ] 본문의 주장/판단에 인용 표시 존재 (예: [1], [2])
- [ ] 인용 표시가 `## 참고 자료`의 항목과 매칭됨
- [ ] `## 참고 자료`에 출처 URL과 원문 내용이 함께 기록됨
